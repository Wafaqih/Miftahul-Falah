# Pondok Pesantren Miftahul Falah - Official Website

Website Resmi Pondok Pesantren Miftahul Falah (miftahulfalah.my.id) - Lembaga Pendidikan Islam Terpadu, Tahfidz Al-Qur'an, dan Pengkajian Kitab Kuning.

## 🚀 Fitur Utama

- **Hero & Profil Pesantren**: Pengenalan visi, misi, dan nilai-nilai pondok pesantren.
- **Jadwal Sholat Real-time**: Widget jadwal sholat otomatis berdasarkan waktu dan lokasi.
- **Pendaftaran Santri Baru (PSB Online)**: Formulir pendaftaran online terintegrasi langsung dengan WhatsApp panitia PSB.
- **Transparansi Biaya Pendidikan**: Rincian biaya pendaftaran, SPP, dan kebutuhan santri secara transparan.
- **Program Unggulan**: Tahfidz Al-Qur'an, Madrasah Diniyah, Kajian Kitab Kuning, Bahasa Arab & Inggris.
- **Galeri Fasilitas & Asrama**: Menampilkan fasilitas asrama, masjid, lab komputer, dan ruang belajar.
- **Donasi & Wakaf Online**: Kanal donasi pembangunan dan beasiswa santri dengan informasi rekening resmi dan konfirmasi instan.
- **Berita & Agenda Santri**: Publikasi kegiatan, kajian rutin, dan berita pesantren.
- **Admin Dashboard**: Panel manajemen untuk memantau pendaftar dan informasi pondok.

## 🛠️ Teknologi yang Digunakan

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4
- **Icons & Animasi**: Lucide React, Motion
- **Tooling**: Node.js & Vite

## 💻 Cara Menjalankan di Komputer Lokal

1. **Clone repository ini:**
   ```bash
   git clone <URL_REPO_GITHUB_ANDA>
   cd <NAMA_FOLDER>
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```
   Aplikasi akan berjalan di `http://localhost:3000` atau `http://localhost:5173`.

4. **Build untuk produksi:**
   ```bash
   npm run build
   ```
   Hasil build siap di-deploy ada di folder `dist/`.
